# مدونة أبو عبد التقنية - Abo Abed Tech Blog

مرحبًا بك في مستودع كود مدونة "أبو عبد" التقنية. هذا المشروع يهدف إلى إنشاء منصة عربية شاملة تقدم محتوى تقني فريد ومميز في عالم الكورسات، الأدوات، المواقع، التطبيقات، وغيرها.

## عن المدونة

مدونة "أبو عبد" هي وجهتك الرقمية لاستكشاف الأدوات والتطبيقات "تحت الأرض" التي لم يكتشفها العالم بعد، بالإضافة إلى مقالات تقنية معمقة ومبسطة، توصيات لأفضل الكورسات المجانية، كنوز جوجل المنسية، واستخدامات عملية للذكاء الاصطناعي.

## الميزات الرئيسية

*   **واجهة أمامية (HTML/CSS/JS):**
    *   تصميم متجاوب وجذاب باللغة العربية.
    *   دعم الوضع الليلي/النهاري.
    *   أقسام متنوعة: مقالات، أدوات، روابط غامضة، اتصل بنا.
    *   مناطق إعلانية مدمجة (Placeholders).
    *   تحسينات SEO أساسية (عناوين، وصف، كلمات مفتاحية، سمات alt).
    *   ملفات `robots.txt` و `sitemap.xml` أساسية.
*   **لوحة التحكم (React - Admin Panel):**
    *   آلية تسجيل دخول مخفية عبر شريط البحث في الصفحة الرئيسية.
    *   إدارة كاملة للمقالات (إضافة، تعديل، حذف) مع حفظ البيانات في `localStorage`.
    *   واجهات أساسية لأقسام الإحصائيات، الإعدادات، الإشعارات، SEO، وإدارة الإعلانات (مع محتوى وهمي).
    *   ميزات متقدمة (واجهات مبدئية):
        *   حفظ تلقائي أثناء تحرير المقالات.
        *   أقسام لإدارة الوسائط والتعليقات (وهمية) داخل صفحة إدارة المقال.
        *   إعدادات متقدمة (مثل تفعيل الوضع الليلي الافتراضي، وضع التخفي - وهمية).

## التقنيات المستخدمة

*   **الواجهة الأمامية:** HTML5, CSS3, JavaScript (ES6+)
*   **لوحة التحكم:** React, Vite, React Router DOM
*   **الأنماط:** CSS Variables, Flexbox, Grid
*   **تخزين البيانات (لوحة التحكم):** `localStorage` (للمقالات، الإشعارات، الإعلانات، والروابط التابعة بشكل وهمي)
*   **توليد ID فريد:** `uuid`

## كيفية تشغيل المشروع (لتطوير لوحة التحكم)

1.  تأكد من تثبيت [Node.js](https://nodejs.org/) (والذي يتضمن npm).
2.  استنسخ المستودع: `git clone <repository-url>`
3.  انتقل إلى مجلد المشروع: `cd abo_abed_blog`
4.  ثبت الاعتماديات: `npm install`
5.  شغل خادم التطوير (Vite): `npm run dev`
    *   سيقوم هذا الأمر بتشغيل لوحة التحكم (عادة على `http://localhost:5173` أو منفذ مشابه). ستحتاج للوصول إليها عبر `admin_dashboard.html` بعد تسجيل الدخول.
6.  للوصول إلى الواجهة الأمامية الثابتة، افتح ملف `index.html` مباشرة في متصفحك أو عبر إضافة مثل "Live Server" في VS Code.

## هيكل المشروع

*   `/` (الجذر): يحتوي على `index.html`, `admin_dashboard.html` (نقطة دخول React)، وملفات الإعداد مثل `vite.config.js`, `package.json`.
*   `/css`: ملفات الأنماط CSS (`style.css`).
*   `/js`: ملفات JavaScript للواجهة الأمامية (`main.js`) ولوحة التحكم (`admin_auth.js`).
*   `/images`: الصور والشعارات (حالياً فارغ أو يحتوي على placeholders).
*   `/pages`: صفحات HTML فرعية إضافية للواجهة الأمامية.
*   `/public`: ملفات عامة مثل `robots.txt`, `sitemap.xml`, وأي صور ثابتة قد تستخدمها React (إذا تم نقلها هنا).
*   `/src`: كود المصدر لتطبيق React الخاص بلوحة التحكم.
    *   `/src/components`: مكونات React المشتركة (مثل `Sidebar.jsx`).
    *   `/src/pages`: مكونات React لصفحات لوحة التحكم (مثل `Dashboard.jsx`, `ManageContent.jsx`, `Settings.jsx`, إلخ).
    *   `/src/App.jsx`: المكون الرئيسي للوحة التحكم الذي يدير التوجيه.
    *   `/src/main.jsx`: نقطة دخول تطبيق React التي تعرض `App` داخل `#root`.
*   `.gitignore`: لتحديد الملفات والمجلدات التي يجب تجاهلها بواسطة Git (مثل `node_modules`).

## ملاحظات

*   المدونة مصممة بشكل أساسي للغة العربية (RTL).
*   العديد من ميزات لوحة التحكم (مثل الإحصائيات المتقدمة، رفع الملفات الفعلي، نظام التعليقات الكامل، حفظ الإعدادات بشكل دائم على خادم) هي حاليًا واجهات وهمية (placeholders) وتتطلب تطويرًا خلفيًا (backend) لتصبح وظيفية بالكامل. تم استخدام `localStorage` كحل مؤقت لمحاكاة حفظ البيانات في لوحة التحكم.
*   للوصول إلى لوحة التحكم، اكتب `launch-access-mas-secret-login` في شريط البحث بالصفحة الرئيسية (`index.html`) واضغط Enter، ثم استخدم بيانات الاعتماد المحددة في `js/admin_auth.js`.
